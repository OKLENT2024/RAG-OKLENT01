# عمارة النظام (System Architecture)

## نظرة عامة

نظام RAG (Retrieval-Augmented Generation) يتكون من أربعة مكونات رئيسية:

1. **معالج البيانات** (Data Processor)
2. **مدير التضمينات** (Embeddings Manager)
3. **محرك البحث** (Retriever)
4. **موليد الإجابات** (Response Generator)

## المكونات الرئيسية

### 1. معالج البيانات (Data Processor)

**الملف**: `src/data_processor.py`

**المسؤوليات**:
- تنظيف وتحضير النصوص
- تقسيم المستندات إلى قطع صغيرة
- استخراج البيانات الوصفية

### 2. مدير التضمينات (Embeddings Manager)

**الملف**: `src/embeddings.py`

**المسؤوليات**:
- تحميل نماذج التضمينات
- حساب متجهات التضمين للنصوص
- إدارة البعد والنماذج

### 3. محرك البحث (Retriever)

**الملف**: `src/retriever.py`

**المسؤوليات**:
- إدارة قاعدة البيانات المتجهة (FAISS/Pinecone)
- البحث عن المستندات ذات الصلة
- حفظ وتحميل الفهاريس

### 4. موليد الإجابات (Response Generator)

**الملف**: `src/generator.py`

**المسؤوليات**:
- توليد الإجابات باستخدام نماذج اللغة
- بناء السياق من المستندات
- تخصيص رسائل النظام

## تدفق البيانات (Data Flow)

```
المستندات الخام
    ↓
معالج البيانات (تنظيف + تقسيم)
    ↓
مدير التضمينات (حساب المتجهات)
    ↓
محرك البحث (حفظ في قاعدة البيانات)
    ↓
الفهرس (FAISS/Pinecone)
    ↑
الاستعلام (Query)
    ↓
محرك البحث (بحث عن المستندات)
    ↓
موليد الإجابات (بناء السياق + LLM)
    ↓
الإجابة النهائية
```

## التكنولوجيات المستخدمة

### المكتبات الأساسية
- **sentence-transformers**: لحساب التضمينات
- **faiss**: لقاعدة البيانات المتجهة
- **openai**: لنموذج اللغة
- **langchain**: لإدارة سير العمل

### أدوات المراقبة والتسجيل
- **loguru**: للتسجيل المتقدم
- **python-dotenv**: لإدارة المتغيرات
