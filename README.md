# مقارنة تطبيق الإيجار — Odoo Rental Comparison Project

## 📋 نظرة عامة على المشروع

هذا مستودع **دراسة ومقارنة فنية ومالية**، وليس مشروع تطوير تطبيق جديد من الصفر.

الهدف: تحديد المسار الأمثل لإدارة الإيجار داخل بيئة **Odoo 17** المستخدمة فعليًا من قِبل
مؤسسة **كوخ المرح والفرح** (تأجير ألعاب فعاليات، بيع ألعاب، تصنيع بلاستيك — 6 فروع)، عبر
مقارنة موثّقة بين:

1. **التطبيق الحالي (`rents`)** — تطبيق إيجار مخصّص (Custom) مثبّت حاليًا على نسخة
   Odoo 17 Community، من تطوير خارجي (Abdalmola Mustafa).
2. **تطبيق Rental الرسمي** — التطبيق المدمج أصلًا ضمن **Odoo 17 Enterprise**.

> ⚠️ **ملاحظة هامة:** هذا المستودع **لا يهدف** إلى بناء تطبيق إيجار عقاري مستقل بتقنية
> Node.js / React / PostgreSQL. أي محتوى سابق في هذا الملف كان يصف اتجاهًا مختلفًا تمامًا
> ولا يعكس نطاق المشروع الفعلي — تم تصحيحه هنا.

## 🎯 أهداف المشروع

- ✅ توثيق الوضع الحالي لتطبيق `rents` (الكود، نماذج البيانات، سير العمل الفعلي بالفروع)
- ✅ تجربة عملية حيّة لتطبيق Rental الرسمي على بيئة Odoo Enterprise تجريبية
- ✅ مقارنة تفصيلية عبر 8 محاور تقنية محورية (راجع `docs/PROJECT_PLAN.md`)
- ✅ بناء نموذج التكلفة الإجمالية للملكية (TCO) لمدة 3 سنوات لكل مسار
- ✅ الوصول إلى توصية موثّقة معتمدة من إدارة كوخ المرح والفرح

## 🚫 خارج نطاق هذا المشروع

- بناء تطبيق إيجار عقاري (Property/Landlord/Tenant) جديد من الصفر
- أي تطوير بتقنيات خارج منظومة Odoo (Node.js, React, PostgreSQL كطبقة بيانات مستقلة)
- تنفيذ الترحيل الفعلي (Migration) — هذه مرحلة لاحقة تُبنى على قرار هذا المشروع فقط

## 📁 هيكل المستودع

```
Rent.management/
├── docs/
│   ├── PROJECT_PLAN.md              # خطة المشروع التفصيلية (مُصحَّحة)
│   ├── CURRENT_STATE.md             # (يُنشأ في المرحلة 1) توثيق الوضع الحالي
│   ├── ENTERPRISE_TRIAL_REPORT.md   # (يُنشأ في المرحلة 2) تقرير التجربة الحية
│   └── COMPARISON_MATRIX.md         # (يُنشأ في المرحلة 3) نتائج المقارنة
├── backend/                          # ملاحظات كود تطبيق rents الحالي (توثيق فقط، ليس تطويرًا)
├── frontend/                         # ملاحظات واجهة تطبيق rents الحالي (توثيق فقط)
├── التطبيق (ir.module.module) (1).xlsx   # جرد التطبيقات المثبتة — مرجع أساسي
├── التطبيق (ir.module.module) (3).xlsx   # جرد محدَّث للتطبيقات المثبتة
└── README.md
```

> ملاحظة: مجلدا `backend/` و`frontend/` من السقالة (scaffold) الأصلية تُستخدمان الآن
> لتوثيق **الكود القائم فعليًا** لتطبيق `rents` المخصّص أثناء المرحلة 1 (تحليل واستكشاف)،
> وليس لبناء تطبيق جديد.
